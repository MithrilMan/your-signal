# Publication checklist

## Platform and provider review

- [ ] Confirm the extension's DOM interaction and text transfer comply with the current X terms and applicable law.
- [ ] Confirm the intended TypeSafe use, retention, location, and contractual terms.
- [ ] Review handling of text visible from protected profiles.
- [ ] Complete trademark and asset provenance checks.

## Product and privacy

- [ ] Verify the product has one clear purpose: personal, reversible filtering of supported X timelines.
- [ ] Publish `PRIVACY.md` at a stable public URL.
- [ ] Enable GitHub private vulnerability reporting.
- [ ] Confirm the Chrome Web Store privacy disclosures match actual behavior.
- [ ] Confirm the API key is session-only by default and never exported or logged.
- [ ] Confirm no telemetry, remote code, or undeclared network destination exists.

## Permissions

- [ ] Justify `storage` for preferences, key storage, counters, and the bounded numeric cache.
- [ ] Justify X host access for reading and changing eligible timeline posts.
- [ ] Justify optional TypeSafe access for direct Jev requests after the user configures a key.
- [ ] Confirm incognito remains disabled.

## Verification

- [ ] Run unit, evaluation, browser, native MV3, and X fixture tests.
- [ ] Run a live test with an authenticated X profile and a limited Jev test key.
- [ ] Verify pause, key removal, permission revocation, provider failure, and offline behavior.
- [ ] Build from a clean checkout and compare staged files with source.
- [ ] Scan the repository history and ZIP for credentials and personal screenshots.
- [ ] Record the ZIP SHA-256 and tag the exact source revision.

## Store materials

- [ ] Prepare accurate listing copy and a single-purpose statement.
- [ ] Provide a 128×128 icon and compliant 1280×800 or 640×400 screenshots using synthetic content.
- [ ] Add repository, support, and privacy URLs.
- [ ] Prepare reviewer instructions and a temporary, limited, revocable Jev key through the private reviewer field.
- [ ] Use deferred publishing, test the approved item, then release deliberately.

Avoid claims that Your Signal replaces X's ranking system, verifies truth, guarantees accuracy, or performs inference locally.
